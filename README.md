# CraftZ SMP - Offizielle Website

Offizielle Webpräsenz für den **CraftZ SMP** Minecraft Bedrock Server (`craftzsmp.xyz`).

## 🎮 Server Info
- **Serveradresse:** `craftz.cybrancee.games` / `play.craftzsmp.xyz`
- **Port:** `60453`
- **Edition:** Minecraft Bedrock Edition (Handy, PC, Windows 10/11, Konsole)

## 📁 Projektstruktur
- `index.html` - Hauptseite (Hero, Features, Beitritts-Anleitung, Team & Stats)
- `style.css` - Moody Minecraft Night Design & Farbschema
- `script.js` - Interaktivität, Kopier-Funktionen & Minecraft-Floating-Text Animationen
- `icons/` - Pixel-Art Icons für die Minecraft-Features
- `craftzlogo.png` - Offizielles CraftZ SMP Logo
- `how-to-join.png` - Ingame-Anleitung für Bedrock
- `mojangles.otf` - Authentische Minecraft-Schriftart
- `spawn.jfif` / `map2d.png` - Server-Hintergrundwelten

## 🚀 Hosting
Diese Seite ist eine statische Website und kann kostenlos auf **Vercel**, **Cloudflare Pages** oder **GitHub Pages** mit der Custom-Domain `craftzsmp.xyz` betrieben werden.
